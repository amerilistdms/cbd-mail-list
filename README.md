# CBD Email Lists

Marketing site for CBD Email Lists, a division of AmeriList.

Built from Cannabis Email Lists Site 2 as a base, with CBD and wellness copy, a sage and teal color system, a CBD logo lockup, and its own imagery while keeping the same pages and content structure.

## Local

```bash
npm install
npm run dev
```

## Stack

Next.js, TypeScript, Tailwind CSS, GSAP
